# ระบบบันทึกสินค้าใหม่ (Product Log)

เว็บแอปสำหรับบันทึกสินค้าใหม่ พร้อมคุมสถานะการลงขายบน Shopee / Lazada
ข้อมูลเก็บในเครื่องผู้ใช้ทั้งหมด (IndexedDB) ใช้งานออฟไลน์ได้ ไม่ต้องมีเซิร์ฟเวอร์

## วิธีใช้

**แบบง่ายสุด** — แตกไฟล์ zip แล้วดับเบิลคลิก `index.html`

**แบบเต็ม (แนะนำ ถ้าอยากติดตั้งเป็นแอป)** — เปิดผ่านเว็บเซิร์ฟเวอร์ เช่น

```
cd product-log
python -m http.server 8000
```

แล้วเปิด `http://localhost:8000` → กดปุ่ม "ติดตั้ง" ในเบราว์เซอร์เพื่อปักหมุดเป็นแอปบนเครื่อง

> เปิดผ่านเซิร์ฟเวอร์เท่านั้นจึงจะใช้ Service Worker (ออฟไลน์/ติดตั้งเป็นแอป) ได้

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครง DOM + CSS ทั้งหมด |
| `config.js` | ค่าคงที่ กติกาสถานะ ตัวช่วยรูปแบบข้อมูล — **แก้ไขตรงนี้เวลาปรับกติกา** |
| `app.js` | ตรรกะทั้งหมด: IndexedDB, หน้าจอ, การบันทึก, ส่งออก |
| `sw.js` + `manifest.json` | ทำให้ติดตั้งเป็นแอปและใช้ออฟไลน์ได้ |

## กติกาหลักของระบบ

```
ไม่ลงขาย → รอคอนเฟิร์ม → คอนเฟิร์มแล้ว → ลงขายแล้ว
                ↓
            ไม่อนุมัติ
```

- เลือกช่องทางไหน สถานะจะเป็น **รอคอนเฟิร์ม** ทันที
- ปุ่ม **"ลงขายแล้ว"** จะโผล่ก็ต่อเมื่อสถานะเป็น *คอนเฟิร์มแล้ว* เท่านั้น (บังคับในโค้ด ไม่ใช่แค่ซ่อนปุ่ม)
- Shopee กับ Lazada มีสถานะแยกกันคนละตัว
- ทุกการเปลี่ยนสถานะถูกบันทึกลงประวัติ พร้อมชื่อผู้ทำและเวลา

## ฟีเจอร์

- **บันทึกสินค้า** — รหัสสินค้า / บาร์โค้ด / ชื่อ / หมวด / หน่วย / ผู้ขาย / ราคา / หมายเหตุ
- **ตรวจซ้ำอัตโนมัติ** — เตือนถ้ารหัสหรือบาร์โค้ดซ้ำกับของเดิม
- **ตรวจ check digit** ของบาร์โค้ด EAN-8 / EAN-13 / UPC-A
- **สถานะสินค้า** — *สินค้าใหม่* หรือ *เปลี่ยนแทนตัวเก่า* (ผูกกับรหัสเดิม แล้วเก็บตัวเก่าเข้าคลังอัตโนมัติ)
- **คิวรอคอนเฟิร์ม** — หน้ารวมทุกอย่างที่ค้างอนุมัติ กดคอนเฟิร์ม/ไม่อนุมัติได้จากหน้าเดียว
- **ค้นหา + กรอง** — ตามรหัส/บาร์โค้ด/ชื่อ/ผู้ขาย และกรองตามประเภท ช่องทาง สถานะ หมวด
- **Dashboard** — จำนวนสินค้า แยกตามประเภท สถานะรายช่องทาง และกราฟ 6 เดือนย้อนหลัง
- **ส่งออก Excel/CSV** — ส่งออกเฉพาะที่กรองอยู่ (UTF-8 BOM เปิดใน Excel ภาษาไทยไม่เพี้ยน)
- **สำรอง/นำเข้า .json** — ย้ายข้อมูลข้ามเครื่องได้

## การปรับแต่งที่ทำได้ง่าย

เปิด `config.js`

- เพิ่มช่องทางขาย (เช่น TikTok Shop) → เพิ่มใน `CHANNELS`
- แก้ชื่อสถานะ หรือเพิ่มขั้นตอน → `CH_STATUS`, `CH_FLOW`, `CH_ACTIONS`
- แก้หมวดสินค้า/หน่วยนับตั้งต้น → `DEFAULT_CATEGORIES`, `DEFAULT_UNITS`
  (หรือแก้หมวดในหน้า "ตั้งค่า" ได้เลยโดยไม่ต้องแตะโค้ด)

## การซิงก์ข้อมูล (Supabase)

ข้อมูลซิงก์ขึ้นฐานกลางอัตโนมัติ — ทุกเครื่องที่เปิดลิงก์เดียวกันเห็นข้อมูลชุดเดียวกัน

- เก็บที่ตาราง `pl_items` (แยกจากตารางอื่นในโปรเจกต์)
- ซิงก์ทุกครั้งที่บันทึก · ทุก 1 นาที · และตอนกลับมาเปิดหน้าเว็บ
- เน็ตหลุดก็ใช้งานต่อได้ ข้อมูลค้างในเครื่องแล้วส่งขึ้นให้เองเมื่อกลับมาออนไลน์
- แก้รายการเดียวกันพร้อมกันจาก 2 เครื่อง → ยึดฉบับที่แก้ล่าสุด
- ปิดการซิงก์ได้ที่หน้า **ตั้งค่า** (กลับไปเก็บเฉพาะในเครื่อง)

**ความปลอดภัย:** `publishable key` ในโค้ดออกแบบมาให้เปิดเผยได้ สิทธิ์คุมด้วย Row Level Security
ฝั่งเซิร์ฟเวอร์ — อ่าน/เพิ่ม/แก้ได้ แต่**ลบทิ้งถาวรไม่ได้** ข้อมูลจึงถูกล้างจากหน้าเว็บไม่ได้

⚠️ ตอนนี้ตั้งเป็น **ไม่ต้องล็อกอิน** = ใครที่มีลิงก์ก็เข้าดู/แก้ได้ ถ้าต้องการจำกัดสิทธิ์
ให้เพิ่มระบบล็อกอิน (Supabase Auth) แล้วแก้ policy ให้เป็น `to authenticated`
